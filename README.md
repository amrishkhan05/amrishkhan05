## 👋 About me

I design and build systems that need to work when real people rely on them. My background spans **backend architecture, distributed services, full-stack delivery, payment integrations, and engineering leadership** — with hands-on experience across aviation, enterprise platforms, and manufacturing.

I'm currently a **Technology Lead Analyst – Backend at Techcarrot**, working on **Etihad Airways** platforms. Before that, I was a **Lead Engineer and Senior Software Engineer at MSYS Technologies (now Aziro)**.

I started with a degree in Electrical & Electronics Engineering. These days, the circuits are mostly distributed systems, and the debugging is somehow just as interesting.

## 🧭 The way I engineer

| Principle | In practice |
| :--- | :--- |
| **Simple isn't the same as easy.** | Good abstractions hide necessary complexity; bad ones just move it around. |
| **Contracts beat assumptions.** | Especially when multiple services and teams share a customer journey. |
| **Small diffs are a feature.** | The easiest code to review, test and reverse is code that didn't change unnecessarily. |
| **Production is part of the design.** | Error handling, observability and recovery belong in the architecture, not in the postmortem. |
